# 实现状态与后续规划

截至本次仓库完善，基础报销、审批、付款、权限、审计、附件、人工确认发票建议已实现。以下项目按实际证据区分状态。

| 项目 | 当前状态 | 后续工作 |
| --- | --- | --- |
| 失败日志 | 独立事务保存；现有回归覆盖 | 日志脱敏策略、监控归集 |
| 提交幂等 | 协调事务、CAS、所有权保护、响应重放；真实 MySQL 并发 / 回滚测试 | Redis 实例故障测试、历史快照清理 |
| RabbitMQ 通知 | 事务 Outbox、发布确认 / 返回检查、退避重试、消费者去重、DLQ 配置；注入故障测试 | 真实 broker 重启 / 断网验收、死信监控与人工重放 |
| 附件存储 | 本地 / MinIO 适配器、哈希去重、持久化回滚与删除补偿 | 真实 MinIO 故障验收、对象存储超时 / 大文件性能测试 |
| 发票识别 | Mock 演示与 AI 适配器、结果校验、人工确认 | 真实供应商契约测试、准确率与费用评估 |
| 自动化交付 | Maven / 前端检查 / E2E、GitHub CI、容器构建与文档 | CI 首次在线执行与多平台启动验收 |
| 生产运维 | 尚未提供完整方案 | 登录限流、TLS、监控告警、备份恢复、压测 |

优先完成外部基础设施验收与后台任务监控，再考虑规则配置、多租户或复杂工作流；不把接口已存在等同于生产可靠性已经验证。
